但目前還有幾個地方我會建議修，不然會跟「Cleaner」這個功能名稱有落差。

需要再修的地方
1. Hiring Now: Freight Coordinator 沒有被清掉

畫面顯示：

Original: Hiring Now: Freight Coordinator
Cleaned: Hiring Now: Freight Coordinator
旁邊還寫 no changes

這裡不對。既然你說 noise removed，應該變成：

Freight Coordinator

Changes made 可以顯示：

Removed hiring phrase: “Hiring Now:”

2. Sample table 裡縮寫沒有展開

目前 sample table 顯示：

Snr Whse Ops Coord → Snr Whse Ops Coord
Jr Logistics Admin → Jr Logistics Admin

但理想應該是：

Snr Whse Ops Coord → Senior Warehouse Operations Coordinator
Jr Logistics Admin → Junior Logistics Administrator

否則使用者會覺得：你說 abbreviation expanded，但其實沒有 expand。

3. DC Supervisor 不應該直接 Out of scope

在 logistics / warehouse context 裡，DC 很常代表 Distribution Centre。
所以 DC Supervisor 比較合理的 cleaned title 是：

Distribution Centre Supervisor

Functional area 可能是：

Warehouse / Distribution

Seniority 可以是：

Supervisor

不應該直接變 Out of scope，除非你的 system 不支援 DC 這個 abbreviation。

4. Import/Export Admin 可以再展開

目前：

Import/Export Admin → Import/Export Admin

建議改成：

Import Export Administrator

或：

Import / Export Administrator

因為 Admin 也是 abbreviation，Cleaner 應該展開。

5. “no changes” 要真的只有沒變時才顯示

如果 cleaned title 跟 original 完全一樣，可以顯示 no changes。
但像 Hiring Now: Freight Coordinator 其實應該有變，所以不能顯示 no changes。

這頁現在的優點

現在排版已經比較像真正的 Cleaner：

有 sample table
有 functional area / seniority / confidence
比之前更能讓使用者理解清理效果

所以不用大改 UI，主要是修 cleaning rules。

Snr → Senior
Jr → Junior
Whse → Warehouse

Admin → Administrator
DC → Distribution Centre
Hiring Now: → remove

現在最重要是讓它真的做到「abbreviations expanded, noise removed, location stripped」。
